Hypervoy: the workplace-operations platform

Envoy wasn't keeping up with how the team actually runs operations, so I designed and built its replacement myself. Hypervoy is an event-driven platform built on webhooks and APIs from Kisi and Brivo access control, with eight custom interfaces built with Claude Code: live room and space booking, desk reservations, package deliveries, live desk usage, badge analytics, and occupancy dashboards. Desk reservations send employees real-time alerts and handle 25+ unique desk situations. Reggie, the visitor agent fleet, plugs in here too — monitoring Hypervoy's visitor data and adding visitors to building security. A monitoring agent watches the ingestion pipeline and caught a silently dropped webhook in production. Migration is in progress — flows are cutting over one at a time, retiring a verified $70K-per-year contract.

03 — Approach

How I build

Four rules that decide what I ship and what I refuse to ship.

01

Automate what you personally run

Every system started as my own manual workflow. I don't guess at requirements. I've done the job the software replaces.

02

Safety before capability

Least-privilege tokens, stage-only spending, PII-safe logging, human approval where it matters. Agents earn autonomy; they don't start with it.

03

Verify, don't hope

Idempotent ingestion, verification before submission, and monitoring agents watching the pipelines; one caught a silently dropped webhook in production.

04

Honest status, always

Live means live. Pre-launch means pre-launch. The same discipline applies to metrics: estimates are labeled as estimates.
